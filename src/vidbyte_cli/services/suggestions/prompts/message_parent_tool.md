Write the message as a direct request the parent can answer in one reply, naming exactly what is missing and why the supplied context does not settle it. The moment the tool records your message, the run ends, and nothing you write after the call is kept or read. Your message is returned to the parent as this run's result, and no suggestions are returned alongside it. Do not use it to report progress, to ask for approval, or to pass along a slate you could have returned yourself.
