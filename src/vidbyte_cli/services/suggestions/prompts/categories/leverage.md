# Leverage

## Purpose

Create one asset, capability, or decision that benefits several credible future tasks. Leverage earns attention because its reuse compounds the value of the initial effort. The suggestion should identify actual future consumers instead of claiming that reuse might someday matter. It should remain small enough to deliver before those consumers arrive.

## Intent

Choose work whose output can be reused with little additional adaptation across at least two future needs. Explain the shared interface or durable property that makes reuse possible.

## Timing

Use this category when current work exposes a repeatable pattern and the cost of capturing it now is lower than recreating it later. Prefer it after one concrete instance provides enough evidence to avoid premature generalization.

## Checks

- Name at least two likely future consumers and the common value they need.
- Define a reusable artifact and a test that shows it works for the current case.

## Cautions

- Do not build generic infrastructure without credible consumers.
- If the value is only a broad future direction, use long-term suggestions or strategy instead.
