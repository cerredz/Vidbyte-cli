# Investigation

## Purpose

Gather the smallest reliable evidence needed for a decision. An investigation narrows a knowledge gap by asking a focused question and choosing a proportionate source. It should end when the evidence is sufficient for the decision, not when every related fact is known. The output is a decision-ready finding, not a research pile.

## Intent

Name the question, the cheapest credible source, the evidence to capture, and the stopping rule. Distinguish missing knowledge from disagreement about what to do.

## Timing

Use this category when an important decision is blocked by an answer the caller does not yet have. Prefer it before speculation becomes implementation or before a consequential choice is made on weak evidence.

## Checks

- State how the evidence will change or confirm a specific decision.
- Set a source boundary and stopping rule so the work cannot expand indefinitely.

## Cautions

- Do not gather information merely because it is interesting or available.
- If a small test can answer the question faster, use an experiment instead.
