# Prerequisite

## Purpose

Create or secure a condition that intended work cannot succeed without. A prerequisite is a real dependency, not a convenient improvement or a general wish for more preparation. The suggestion should explain what becomes possible once the condition exists. It should identify the smallest action that establishes the condition.

## Intent

Expose the missing capability, decision, input, access, or resource that blocks the planned work. Connect the condition directly to the work it unblocks.

## Timing

Use this category before attempting work that would otherwise fail, stall, or create rework. Prefer it when the dependency is known and can be addressed before the main action.

## Checks

- State why the condition is necessary rather than merely useful.
- Define observable evidence that the prerequisite is ready and usable.

## Cautions

- Do not label optional polish as a prerequisite.
- If the dependency is uncertain, propose an investigation or experiment instead.
