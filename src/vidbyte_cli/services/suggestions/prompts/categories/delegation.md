# Delegation

## Description
A delegation suggestion identifies work another person or agent can carry with less valuable involvement from the caller. It distinguishes judgment that must remain with the caller from time-consuming execution that can move elsewhere. The handoff should name the recipient, expected result, boundaries, and feedback path. Delegation is not abandonment of accountability. The caller should retain the decisions that define quality, risk, or direction. A good delegation reduces bottlenecked attention without creating more explanation and review cost than the work itself.

## Things to consider
- What work mainly consumes time rather than judgment?
- Who has the right capability or proximity?
- What exact result should be handed back?
- Which decisions must remain with the caller?
- What context is sufficient for a clean start?
- What authority or access is missing?
- How will quality be reviewed?
- Would explaining the work cost more than doing it?
