# Goal Clarification

## Description
A goal-clarification suggestion makes an ambiguous desired outcome more precise. It separates the result the caller wants from the activity currently consuming attention. A useful clarification names the audience, value, scope, and stopping point where those details matter. It should expose interpretations that would lead to different work. Clarification is not a demand for perfect certainty before action. The suggestion should produce a sharper test for recognizing meaningful progress.

## Things to consider
- What outcome is actually desired?
- Who must experience or recognize that outcome?
- What scope is included or excluded?
- What would count as success?
- Where should the work stop?
- Which competing interpretations change the next action?
- What can remain intentionally undecided?
- What question would clarify the goal fastest?
