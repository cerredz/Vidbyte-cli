# Stop or Defer

## Description
A stop-or-defer suggestion protects attention from work whose present value does not justify its cost. Stopping ends a direction when the case against continuation is strong. Deferral preserves the option while naming the condition that would make it worth revisiting. The recommendation should explain what more valuable work is displaced by continuing. It should preserve enough state for a responsible restart when appropriate. This category is a decision about allocation, not a way to hide uncertainty or avoidance.

## Things to consider
- What work is being stopped or postponed?
- What evidence makes continuation unattractive now?
- Which higher-value commitment would benefit?
- Is the decision a stop or a deferral?
- What trigger would justify reconsideration?
- What state must be preserved?
- Who needs to know about the change?
- What cost would an ambiguous pause create?
