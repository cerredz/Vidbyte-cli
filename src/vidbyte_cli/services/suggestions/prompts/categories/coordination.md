# Coordination

## Description
A coordination suggestion resolves ownership, sequencing, communication, or dependency alignment across participants. It turns shared ambiguity into explicit commitments.

## Goal
Make interdependent work progress without duplication, hidden waits, or conflicting assumptions.

## Intent
Use this type when several actors or workstreams need a named interface or decision to move safely.

## Timeline
Coordinate before dependent work diverges or blocks. Reconfirm later when scope, ownership, or sequence materially changes.

## Checklist
- Name owners and affected workstreams.
- Define the dependency or decision boundary.
- Establish the next exchange and confirmation signal.

## Cautions
Do not add meetings where a written contract is sufficient. Avoid shared ownership with no accountable decision maker.
