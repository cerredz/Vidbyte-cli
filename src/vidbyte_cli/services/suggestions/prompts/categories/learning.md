# Learning

## Description
A learning suggestion targets knowledge or skill that will improve an upcoming real task. It links learning to an application so curiosity does not become an open-ended detour. The smallest useful lesson is usually better than a broad curriculum. Repeated difficulty can signal that a durable capability is worth building. The suggestion should explain how the caller will practice or verify the new understanding. Use this category when a targeted capability gap, rather than missing motivation or information alone, limits the next useful action.

## Why use / use cases
- [ ] **A repeated task exposes the same capability gap.** The caller may keep relearning or relying on help for one important operation. Use this category when building the skill will improve several upcoming attempts.
- [ ] **An upcoming decision needs domain understanding.** The caller may not yet know which evidence, tradeoff, or mechanism matters. Suggest focused learning when a small lesson can materially improve that decision.
- [ ] **A tool or method is blocking independence.** The caller may be unable to inspect, create, or change the relevant work without outside assistance. Use it when a bounded practice path can remove that dependency.
- [ ] **A mistake reveals a durable lesson.** The immediate error may be fixed, but the same pattern could recur. Recommend learning when extracting and practicing the underlying principle is worth more than a one-time patch.
- [ ] **A new responsibility requires readiness.** The caller may soon own a process, system, or conversation they have not handled before. Use the category when preparation should build real competence rather than only collect material.
- [ ] **A short tutorial can unlock a concrete task.** The caller may need one concept, technique, or workflow instead of a full curriculum. Suggest the smallest lesson whose application can be observed in the task.
- [ ] **The cost of repeated delegation is growing.** A capability may be worth internalizing when relying on others creates delay or coordination burden. Use it when learning will improve judgment or execution enough to repay the investment.
- [ ] **A learning path needs a proof of understanding.** Reading or watching alone may create false confidence. Recommend this category when practice, explanation, or a completed application can verify the new capability.

## Things to consider
- What precise skill or knowledge gap affects the goal?
- What evidence shows the gap is real and consequential?
- Which upcoming task or decision will apply the learning?
- What is the smallest useful lesson, practice, or demonstration?
- Which source is trustworthy, accessible, and suited to the level of need?
- How will understanding be checked through action or explanation?
- What can be deferred until after the immediate commitment?
- What future action, judgment, or independence should improve?

## When not to use
Do not use this category when the missing issue is a fact that can be quickly investigated or a prerequisite that someone else must provide. Avoid it when learning would only delay a safe action or when no application and proof of understanding can be named. If the capability is needed immediately to unblock work, use prerequisite; if the goal is to capture a reusable organizational asset, use leverage.
