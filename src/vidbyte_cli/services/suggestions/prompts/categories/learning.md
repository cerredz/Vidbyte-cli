# Learning

## Description
A learning suggestion targets knowledge or skill that will improve an upcoming real task. It links learning to an application so curiosity does not become an open-ended detour. The smallest useful lesson is usually better than a broad curriculum. Repeated difficulty can signal that a durable capability is worth building. The suggestion should explain how the caller will practice or verify the new understanding. Learning is valuable when it changes the quality or independence of a near-term decision.

## Things to consider
- What knowledge gap affects the goal?
- Has the gap caused repeated difficulty?
- Which upcoming task provides an application?
- What is the smallest useful learning activity?
- Which source is trustworthy and accessible?
- How will understanding be checked?
- What can be learned after the immediate task?
- What decision or action should improve afterward?
