# Creative Exploration

## Description
A creative-exploration suggestion deliberately expands the possibility space beyond the caller’s current assumptions. It changes an input such as audience, medium, constraint, sequence, scale, or definition of value to reveal different options. The output should be a concrete set of meaningfully distinct possibilities rather than a vague invitation to brainstorm. Novelty is useful only when it creates contrast that can inform a later choice. A bounded exploration keeps idea generation from becoming an unending detour. Use this category when the caller needs new directions before choosing or testing one.

## Why use / use cases
- [ ] **The current options all look alike.** Repeated proposals may share an assumption about audience, mechanism, or acceptable scope. Use this category to vary the assumption and produce options that can genuinely change the decision.
- [ ] **A familiar solution pattern is exhausted.** The caller may keep optimizing a route that no longer produces useful gains. Suggest creative exploration when changing the frame or medium could reveal a different mechanism.
- [ ] **The audience or beneficiary is too narrowly defined.** A new user, stakeholder, or setting may expose an unmet need or different value exchange. Use the category when broadening the perspective can create testable alternatives.
- [ ] **Constraints are hiding rather than shaping ideas.** A budget, deadline, policy, or resource limit may be treated as a reason to stop exploring. Recommend a constrained exercise that turns the limit into a source of distinct possibilities.
- [ ] **A future scenario deserves preparation through options.** The caller may need several plausible responses before conditions are known. Use this category when the exercise ends in a small set of options tied to recognizable signals.
- [ ] **A cross-functional group is stuck in one vocabulary.** People may be unable to see options because they describe the problem in the same terms. Suggest a concrete reframing, analogy, or role shift that changes the available language.
- [ ] **A small amount of novelty could unlock a better test.** One unusual concept may suggest a sharper experiment or product interaction. Use it when the exploration has a path back to the original goal and a selection rule.
- [ ] **The cost of exploring is low and the cost of narrowing too early is high.** Early commitment may discard an option before its value is visible. Recommend bounded exploration when a short session can preserve meaningful choice without delaying a necessary decision.

## Things to consider
- Which assumption, input, or constraint should the exploration deliberately vary?
- How many options are enough to create contrast without producing noise?
- What makes the options materially different in mechanism or value?
- Which audiences, contexts, or mediums have not been represented?
- What rule prevents familiar variants from filling the slate?
- What time, resource, and attention boundary contains the exercise?
- Which signal or criterion identifies a promising direction?
- How will a selected idea return to the original goal or a concrete test?

## When not to use
Do not use this category when the caller already has a clear route and needs execution, verification, or prioritization. Avoid it when the request is only for more ideas but no decision, selection rule, or boundary exists. If the desired novelty comes from borrowing a tested mechanism from another field, use cross-domain; if a single interpretation must change, use reframing.
