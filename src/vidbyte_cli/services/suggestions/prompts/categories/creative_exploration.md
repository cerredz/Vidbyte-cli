# Creative Exploration

## Description
A creative-exploration suggestion expands the possibility space beyond the caller's current assumptions. It should produce a concrete exercise, constraint change, or direction rather than a vague invitation to brainstorm. The exploration may vary the audience, medium, sequence, scale, or definition of value. It should create useful contrast among possibilities instead of many cosmetic variants. A bounded exploration keeps novelty from becoming an unending detour. The caller should learn which new direction deserves a more serious test.

## Things to consider
- Which current assumption limits the options?
- What audience, medium, or constraint could change?
- Which possibility would normally be overlooked?
- How can the exploration stay concrete?
- What contrast would make options meaningfully different?
- What time or effort boundary is appropriate?
- What signal identifies a promising direction?
- How will ideas return to the original goal?
