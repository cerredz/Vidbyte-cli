# Technical Possibilities

## Description
A technical-possibilities suggestion explores what technology could make materially better or possible. It stays at the level of capability and user or system value rather than prescribing implementation details. The possibility should connect to a real constraint, opportunity, or desired outcome in the caller's context. It should identify what new behavior the capability would enable. Technical novelty is not valuable when it adds complexity without changing the result. The suggestion should propose a feasibility check that can separate a promising possibility from an attractive fantasy.

## Things to consider
- What outcome would the capability improve?
- Which current constraint does it address?
- What new behavior would become possible?
- What evidence suggests the possibility is relevant?
- What complexity or dependency would it add?
- Which users or systems would benefit?
- What feasibility question matters first?
- What result would make the possibility not worth pursuing?
