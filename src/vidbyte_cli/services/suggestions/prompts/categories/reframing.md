# Reframing

## Description
A reframing suggestion offers a different interpretation of the problem that could change what the caller does next. It looks beneath repeated symptoms for an assumption about cause, ownership, value, or constraint. The new frame should remain connected to the supplied evidence rather than becoming a clever slogan. A useful reframe changes the set of available actions or the tradeoffs among them. It should be held as a lens to test, not asserted as certain fact. The caller should gain a concrete next question or experiment from the changed interpretation.

## Things to consider
- What symptom keeps recurring?
- Which assumption about the problem is unexamined?
- What alternate cause or boundary fits the evidence?
- How would the new frame change action?
- What evidence supports or challenges it?
- Which old interpretation remains useful?
- What small test could distinguish the frames?
- What decision follows if the reframe holds?
