# Experiment

## Description
An experiment is a bounded intervention designed to reduce important uncertainty. It produces evidence for a decision rather than a miniature unlabeled rollout.

## Goal
Learn enough about one uncertain relationship to choose a better next action.

## Intent
Use this type when competing beliefs can be separated by a small, reversible test.

## Timeline
Prefer experiments that finish within a day or one decision cycle. Run them before large commitments that depend on their result.

## Checklist
- Name the hypothesis and competing explanation.
- Define the smallest discriminating intervention.
- Set evidence and stopping criteria in advance.

## Cautions
Do not run an experiment whose result cannot change a decision. Limit exposure and preserve reversibility.
