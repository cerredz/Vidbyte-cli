# Experiment

## Description
An experiment is a bounded intervention that separates competing explanations or choices. It is valuable when the result can change what the caller does next. The test should be small enough to run reversibly and specific enough to produce interpretable evidence. A useful experiment names the uncertainty rather than disguising a rollout as learning. It should protect people, resources, and existing progress from unnecessary exposure. The result deserves a predefined decision rule so the test does not become indefinite activity.

## Things to consider
- What uncertainty is important enough to test?
- Which competing explanations or options are being separated?
- What is the smallest discriminating intervention?
- What result would support each explanation?
- What result would stop or redirect the work?
- How will exposure and reversibility be protected?
- What resources and participants are actually needed?
- What decision will the evidence inform?
