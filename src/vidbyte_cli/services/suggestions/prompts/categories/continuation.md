# Continuation

## Purpose

Advance an accepted plan from its current state to the next bounded step. The direction and desired outcome should already be clear enough to preserve. The suggestion should name an action that can start without reopening settled strategy. It should produce a recognizable result before the next planning point.

## Intent

Prefer the smallest unblocked action that moves the existing plan forward. Keep the action narrow enough that a fresh agent can own it and report completion.

## Timing

Use this category after a plan, decision, or milestone has been accepted and the next operation is available. Do not use it to disguise a new direction as routine execution.

## Checks

- Name the accepted plan, next action, owner, input, output, and completion signal.
- Confirm that the action does not depend on an unresolved decision or missing prerequisite.

## Cautions

- If the goal or direction is unclear, use a clarification or strategy-oriented category.
- If the current plan is complete, do not invent another continuation step.
