# Suggestions service

Local next-action agent: goal plus optional caller context in, ranked ideas with deterministic handoffs out. `service.py` owns complete critic-to-generator refinement cycles. The generator keeps one persistent SDK thread, while each fresh critic returns per-candidate critiques with rubric scores plus one whole-slate signal block that the SDK context manager places at the end of the generator conversation. Per-candidate critiques are advisory traceability on final ideas; the generator owns the replacement slate. `sdk.py` is the only SDK import; prompts live in `prompts/`.
