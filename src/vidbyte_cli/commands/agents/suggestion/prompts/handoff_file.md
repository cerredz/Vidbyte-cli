A prior handoff describes task state transferred from another agent or workflow. Its structured fields preserve decisions, progress, constraints, and other state without requiring a prose reconstruction.

Version validation prevents a document with different semantics from being interpreted accidentally. Unreadable, malformed, or unsupported handoffs fail before candidate generation.

Omission means no prior handoff was provided and makes no claim about whether one exists elsewhere. Accepted content remains context only and does not grant execution authority.
