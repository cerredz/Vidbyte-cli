View one expands a single category into its full high-level definition. Pass the exact category identifier shown by the all-categories view. The result includes the authored description and the considerations that guide suggestions of that type.

Use this view when a caller needs to understand the distinction between nearby categories before selecting one. The command reads packaged content locally and makes no model call. An unknown identifier is rejected before any output is produced.

The expanded definition is informative guidance, not an instruction to execute work. It preserves the category's conceptual boundary while leaving concrete actions to a later suggestion run.
