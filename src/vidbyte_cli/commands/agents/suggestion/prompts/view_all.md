View all returns the high-level summary of every category in the suggestion registry. It is useful when an agent needs to choose a reasoning lens before building a run.

The default output is the same complete summary list, so callers do not need a separate discovery step. Use the expanded view when the short description is not enough to decide which category fits the goal. This read does not invoke a model or inspect credentials.

The summaries come from the same registry that validates run selections and supplies category context. They describe opportunity types at a conceptual level and intentionally omit provider, prompt, and implementation mechanics.
