# Agents commands

`agents suggest run` generates ideas, `categories` lists the taxonomy, and `handoff` extracts one packet. The `project create` and `project list` verbs manage small local JSON memory projects, while `feedback accept` and `feedback reject` append explicit user reactions to one project. All commands are local and free, and project or feedback commands never call a model. Run accepts narrow context flags, including repeatable `--completed`, `--in-progress`, and `--future-intended-work` values. Future intended work describes planned but unfinished work, so a suggestion may refine or sequence it without claiming it is complete.
